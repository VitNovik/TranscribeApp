# TranscribeApp

Нативное macOS приложение для локальной транскрибации аудио и видео файлов с автоматическим определением и разделением спикеров (диаризация).

## Возможности

- **Транскрибация** - преобразование аудио/видео в текст с помощью Whisper
- **Диаризация** - автоматическое разделение по спикерам с помощью pyannote.audio
- **Управление спикерами** - переименование и цветовая маркировка
- **Локальная обработка** - все данные обрабатываются на вашем устройстве
- **Поддержка форматов**:
  - Аудио: MP3, WAV, M4A, FLAC, OGG
  - Видео: MP4, MOV, AVI, MKV, WebM

## Требования

- macOS 10.15 или новее
- Apple Silicon (M1/M2/M3/M4) или Intel
- FFmpeg (для обработки видео)
- Python 3.9+ (для Whisper и pyannote)

## Установка

### Вариант 1: Скачать готовое приложение

1. Перейдите в [Releases](https://github.com/VitNovik/TranscribeApp/releases)
2. Скачайте последнюю версию `TranscribeApp-v*.dmg`
3. Откройте DMG файл
4. Перетащите TranscribeApp в папку Applications
5. Запустите приложение

### Вариант 2: Сборка из исходников

```bash
# Клонировать репозиторий
git clone https://github.com/VitNovik/TranscribeApp.git
cd TranscribeApp

# Запустить скрипт установки (устанавливает зависимости)
bash scripts/setup.sh

# Или установить вручную:
brew install ffmpeg
npm install
bash scripts/download_models.sh medium

# Запустить в режиме разработки
npm run tauri:dev

# Или собрать приложение
npm run tauri:build
```

## Использование

1. **Добавить файл**: Нажмите `+` или перетащите файл в окно
2. **Дождитесь обработки**: Приложение извлечёт аудио, транскрибирует и определит спикеров
3. **Просмотрите результат**: Кликните на транскрипцию в списке
4. **Переименуйте спикеров**: В панели справа нажмите на имя спикера
5. **Экспортируйте**: Нажмите кнопку Export для сохранения в TXT, SRT или JSON

### Горячие клавиши

- `⌘ + N` - Новая транскрипция
- `⌘ + ,` - Настройки
- `⌘ + L` - Логи
- `Escape` - Назад / Закрыть модальное окно

## Настройки

### Модели Whisper

| Модель | Размер | Качество | Скорость |
|--------|--------|----------|----------|
| Tiny | ~75 MB | Низкое | Очень быстро |
| Base | ~140 MB | Среднее | Быстро |
| Small | ~460 MB | Хорошее | Средне |
| Medium | ~1.5 GB | Высокое | Медленно |
| Large-v3 | ~3 GB | Максимальное | Очень медленно |

Рекомендуется модель **Medium** для баланса качества и скорости.

### Диаризация (разделение по спикерам)

Для работы диаризации требуется:
1. Установить `pyannote.audio`: `pip install pyannote.audio`
2. Получить токен Hugging Face: https://huggingface.co/settings/tokens
3. Принять условия использования модели: https://huggingface.co/pyannote/speaker-diarization-3.1
4. Установить переменную окружения: `export HF_TOKEN=your_token`

## Технологии

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Backend**: Rust, Tauri 2.0
- **База данных**: SQLite
- **Транскрибация**: Whisper (через whisper.cpp или Python)
- **Диаризация**: pyannote.audio
- **Обработка медиа**: FFmpeg

```bash

npm install

# Запустить в режиме разработки
npm run tauri:dev

# Проверка типов TypeScript
npm run typecheck

# Линтинг
npm run lint

# Сборка для продакшена
npm run tauri:build
```

### Примечание для Linux окружений

Если вы запускаете `cargo check` или `npm run tauri:build` в Linux (например, в CI контейнере),
нужно установить системные зависимости для `glib` и `pkg-config`.
Пример для Debian/Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y libglib2.0-dev pkg-config
```

## Известные ограничения

- Диаризация требует Hugging Face токен и интернет-соединение для первичной загрузки модели
- Whisper Python требует Python 3.9+ и может использовать значительный объём RAM
- Обработка длинных файлов (>2 часов) может занять продолжительное время
